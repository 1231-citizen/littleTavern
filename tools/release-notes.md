# 小酒馆 v1.0.0

第一版：一个面向手机端的「类酒馆」角色扮演对话应用，Flutter / Android 原生实现，直连 DeepSeek（及任意 OpenAI 兼容接口）。

## 这一版有什么

**对话**
- 紧凑气泡流，头像固定在气泡内部左上角
- 点击气泡改内容 —— 保存后清除该条之后的全部消息，从这一条重新开始
- 长按弹出适中的操作栏：复制 / 修改 / 思维链开关 / 删除这条及其后
- 流式逐字输出，可随时停止；中断时若尚无内容则自动撤回气泡
- 思维链：解析 `reasoning_content`，每条消息独立展开收起，且不回传给模型

**角色卡（对话的前提）**
- 三要素：人物名称 / 人物设定 / 人物外在形象，缺名称不许保存
- 形象使用 emoji + 柔和色调，无需相册权限
- 没有角色卡时输入框禁用，主区只留「创建角色卡」一条路径

**左上角「栏」**
- 世界背景设定（当前对话的前因后果）
- API 接入：接口地址 / Key / 模型 / 推理等级四档 / 温度 / 最大输出 / 流式开关 / 附加 JSON 参数 / 测试连接
- 全局用户设定
- 酒馆人物管理

**设计**
- 日系清新风：Ma 留白、侘寂、发丝级 0.8px 边框、无可见阴影、500ms 慢动效
- 全局单字重中文楷体（霞鹜文楷 Light），从根上避免粗体

## 说明

- 数据（角色卡 / 会话 / 用户设定 / API 配置）全部保存在本机
- API Key 只写入本机存储，请求由设备直发，不经过任何中转服务器
- `app-release.apk` 使用 debug 签名，仅供自行安装体验；上架需自行配置签名

## 已知限制

- 严格只做两人对话（用户 + 单个 AI 角色），没有群聊
- 头像为 emoji + 色调，暂不支持真实图片
- 没有角色卡导入 / 导出，没有世界书关键词触发
- 会话是线性的，没有分支树与重新生成
